# 0000. Decision in a few words

Status: proposed, YYYY-MM-DD. Deciders: jjforge maintainers.

## Context

The forces at play, and the options considered. Name each option, and say what
it costs.

## Decision

The option chosen, stated as rules. A rule that a check enforces names the
check.

## Consequences

Only what follows from the decision and isn't obvious from it. Leave this
section out when it would say nothing.
