# jjforge

A forge for [Jujutsu](https://github.com/jj-vcs/jj) repositories. For now it is
an echo server: every component exists, builds, deploys, and passes one message
along, and does nothing else.

Start with [docs/architecture.md](docs/architecture.md). Building and running
it is in [docs/development.md](docs/development.md). The shared cluster it runs
on lives in [nca-apprentices/infra](https://github.com/nca-apprentices/infra).
